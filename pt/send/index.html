Às vezes as palavras são mais fáceis de enviar do que de dizer.

Escolha o sentimento. Escreva uma linha. A pessoa abre uma página com seu recado em cima e o sentimento embaixo.

Não sabe o que escrever? Escolha um sentimento e a gente acha as palavras →

O link dela

Nada do que você digita aqui é enviado a lugar nenhum. Seu recado é codificado dentro do próprio link — nenhum servidor o vê, e não há banco de dados aqui para guardá-lo.
