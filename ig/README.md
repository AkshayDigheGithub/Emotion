# ig/

Instagram assets for the posting calendar, served as static files so Metricool
can fetch them at publish time.

Generated by the pipeline in `InstaChannelAutomation`, not edited by hand:

- `*.png` — 1080x1350 post cards (1080x1920 for reel posters)
- `*.mp4` — 1080x1920 reels, H.264 / yuv420p, 12s

Filenames match the calendar in `config/calendar.json` (`dayNN-<kind>-<slug>`).
Regenerate with `npm run assets`.
